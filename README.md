# Модульна контрольна робота

**Виконав:** Вівчар Вадим Вікторович  
**Група:** АЛК-43  
**Факультет:** Інженерія програмного забезпечення  

---

## Опис проєкту

Цей репозиторій містить інтерактивний приклад розв’язання завдань другого рівня модульної контрольної роботи з теми **«Теорія ймовірностей та математична статистика»**.

У програмі реалізовано завдання 9–16. Для кожного завдання подано умову, пояснення вибору формули, підстановку числових значень, обчислення та відповідь.

---

## Що реалізовано

У проєкті показано використання таких тем і формул:

- правило множення ймовірностей незалежних подій;
- формула повної ймовірності;
- формула Байєса;
- формула Бернуллі;
- локальна теорема Муавра–Лапласа;
- інтегральна теорема Муавра–Лапласа;
- формула Пуассона;
- закон розподілу дискретної випадкової величини.
